   • One time only random game crash
   • Game crashes during endurance testing
     before 8 hours have passed.
   • Loading crashes
   • Graphic glitches (drop out, seaming)
   • Audio popping or cut off

CONFIDENTIAL   PlayStation Developer Seminar / Summer ‘97/ Passing QA …the first time
How to “Blaze” through SCEA Third Party QA


• Thoroughly test all aspects of the game.
• Verify the Technical Approval checks.
• Check all items on the TRC and Guideline
  checklists.
• Submit a completed/accurate manual.
• Use the SCEA Website for obtaining the latest
  files and up to date information.
